## Введение

Git — это распределённая система контроля версий, которая позволяет отслеживать изменения в коде, работать в команде и управлять историей проекта.

## Основные команды

### Инициализация репозитория
```bash
git init
```
Создаёт новый локальный репозиторий в текущей папке.

### Клонирование репозитория
```bash
git clone https://github.com/user/repo.git
```
Копирует удалённый репозиторий на ваш компьютер.

### Добавление изменений
```bash
git add .
git add filename
```
`git add .` добавляет все изменённые файлы. `git add filename` добавляет конкретный файл в staging area.

### Создание коммита
```bash
git commit -m "Описание изменений"
```
Сохраняет изменения в локальном репозитории с описанием.

### Отправка изменений на сервер
```bash
git push origin main
```
Отправляет ваши коммиты на удалённый репозиторий.

### Получение изменений с сервера
```bash
git pull origin main
```
Загружает и объединяет изменения с удалённого репозитория.

### Просмотр статуса
```bash
git status
```
Показывает текущее состояние репозитория (какие файлы изменены, добавлены и т.д.).

### История коммитов
```bash
git log
git log --oneline
```
Показывает историю коммитов. `--oneline` выводит более компактный вид.

## Работа с ветками

### Создание новой ветки
```bash
git branch feature-name
```

### Переход на ветку
```bash
git checkout feature-name
```

### Создание и переход на новую ветку за раз
```bash
git checkout -b feature-name
```

### Просмотр всех веток
```bash
git branch -a
```

### Удаление ветки
```bash
git branch -d feature-name
```

### Объединение ветки с main
```bash
git checkout main
git merge feature-name
```

## Коллаборация

### Создание Pull Request

1. Создайте новую ветку для вашей фичи
2. Сделайте коммиты с изменениями
3. Запушьте ветку: `git push origin feature-name`
4. На GitHub откройте Pull Request
5. Получите review от коллег
6. Объедините PR в main

### Решение конфликтов

Если при слиянии возникает конфликт, Git отметит проблемные места в файле. Вам нужно:

1. Вручную разрешить конфликты (выбрать нужный вариант кода)
2. Добавить файл: `git add filename`
3. Завершить слияние: `git commit -m "Resolve merge conflict"`

## Полезные советы

### Просмотр различий между версиями
```bash
git diff
git diff branch1 branch2
```

### Отмена последнего коммита (если не запушен)
```bash
git reset --soft HEAD~1
```

### Просмотр кто и когда изменил строку
```bash
git blame filename
```

### Создание тега
```bash
git tag v1.0.0
git push origin v1.0.0
```

### Сохранение незакоммиченных изменений
```bash
git stash
git stash pop
```
