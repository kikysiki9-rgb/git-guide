# Git Шпаргалка

Быстрый справочник самых полезных команд Git.

## Начало работы

| Команда | Описание |
|---------|---------|
| `git config --global user.name "Name"` | Установить имя пользователя |
| `git config --global user.email "email@example.com"` | Установить email |
| `git init` | Инициализировать новый репозиторий |
| `git clone <url>` | Клонировать репозиторий |

## Основные операции

| Команда | Описание |
|---------|---------|
| `git status` | Статус репозитория |
| `git add <file>` | Добавить файл в staging area |
| `git add .` | Добавить все изменённые файлы |
| `git commit -m "message"` | Создать коммит |
| `git push origin <branch>` | Отправить на удалённый репозиторий |
| `git pull origin <branch>` | Получить обновления с сервера |
| `git fetch` | Получить информацию об обновлениях (без слияния) |

## Просмотр истории

| Команда | Описание |
|---------|---------|
| `git log` | История всех коммитов |
| `git log --oneline` | Компактная история |
| `git log --graph --all --oneline` | Визуальное дерево веток |
| `git diff` | Различия неподготовленных файлов |
| `git diff --staged` | Различия подготовленных файлов |
| `git show <commit>` | Показать конкретный коммит |

## Работа с ветками

| Команда | Описание |
|---------|---------|
| `git branch` | Список локальных веток |
| `git branch -a` | Все ветки (локальные и удалённые) |
| `git branch <name>` | Создать новую ветку |
| `git checkout <branch>` | Переключиться на ветку |
| `git checkout -b <branch>` | Создать и переключиться на ветку |
| `git merge <branch>` | Слить ветку в текущую |
| `git branch -d <branch>` | Удалить ветку (если слита) |
| `git branch -D <branch>` | Удалить ветку (принудительно) |

## Отмена изменений

| Команда | Описание |
|---------|---------|
| `git restore <file>` | Отменить изменения в файле |
| `git restore --staged <file>` | Убрать файл из staging area |
| `git reset HEAD~1` | Отменить последний коммит (сохраняет изменения) |
| `git reset --hard HEAD~1` | Отменить последний коммит (удаляет изменения) |
| `git revert <commit>` | Создать новый коммит, отменяющий изменения |

## Теги

| Команда | Описание |
|---------|---------|
| `git tag` | Список тегов |
| `git tag <version>` | Создать тег |
| `git tag -a <version> -m "message"` | Создать аннотированный тег |
| `git push origin <version>` | Отправить тег на сервер |
| `git push origin --tags` | Отправить все теги |

## Сохранение работы

| Команда | Описание |
|---------|---------|
| `git stash` | Сохранить незакоммиченные изменения |
| `git stash list` | Список сохранённых наборов |
| `git stash pop` | Восстановить последний набор |
| `git stash drop` | Удалить последний набор |

## Полезные флаги

- `-m` — сообщение (commit, merge, branch)
- `-a` — все файлы (add, branch)
- `-f` или `--force` — принудительно
- `-v` или `--verbose` — подробный вывод
- `--amend` — изменить последний коммит
- `-u` или `--set-upstream` — установить ветку по умолчанию (push)
